# EZOA-TO Flutter

- Stack : Flutter 3.x, Riverpod, go_router, Dio, sqflite
- API : `lib/core/network/api_client.dart` (parité `mobile-expo-legacy/src/core/api/client.ts`)
- Brand : #006A4E, slogan « Archive. Révise. Excelle. »
- Lancer émulateur : `flutter run --dart-define=USE_EMULATOR_HOST=true`
- Lancer appareil physique : `flutter run --dart-define=DEV_LAN_HOST=<IP-LAN>`
