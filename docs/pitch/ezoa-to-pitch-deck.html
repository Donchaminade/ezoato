Le problème

Les épreuves se perdent. Les élèves cherchent partout.

  • Sujets d’examens et compositions dispersés entre WhatsApp, photocopies et « anciens »
  • Pas d’archive fiable, filtrable par classe, matière, établissement ou examen national
  • Révisions inégales selon le réseau social — pas selon le mérite

La solution

Une bibliothèque nationale d’épreuves, dans la poche.

  • Accès centralisé web + mobile aux devoirs, compositions et examens (CEPD, BEPC, BAC…)
  • Recherche Archives, favoris, téléchargements PDF, mode hors ligne
  • Contenu vérifié : soumission communautaire + validation humaine avant publication
