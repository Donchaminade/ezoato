Le problème

Les épreuves se perdent.

  • Accès fragmenté (WhatsApp, photocopies)
  • Temps perdu avant les examens
  • Pas de source fiable locale au Togo
  • Révisions inégales — le réseau décide
  • Aucun filtre classe / matière / examen

La solution

Une archive nationale, dans la poche.

  • CEPD · BEPC · BAC + devoirs / compositions
  • Web + mobile — chercher, télécharger, réviser
  • Favoris, PDF, mode hors ligne
  • Soumission communautaire + validation humaine
  • Promesse : Archive. Révise. Excelle.

Produit

App & web opérationnels.

  • Archives filtrables (ville, matière, classe)
  • Soumettre : photos → PDF → validation
  • Pro + achat à l’unité (Mobile Money)
  • Compte : favoris, bibliothèque, hors ligne
  • Stack : Flutter · React · PHP/MySQL

Marché

Togo → AO francophone.

  • ~912 k élèves secondaire Togo (MEN)
  • TAM ~10 M — secondaire AO francophone
  • SAM ~370 k — smartphone / internet utile
  • SOM 3–8 k Pro payants (18–24 mois)
  • Estimations — détail en notes orateur

Business model

Freemium + Mobile Money.

  • Devoirs & compositions gratuits
  • Pro : 1 000 FCFA / 6 mois (examens illimités)
  • À l’unité : 100–200 FCFA / examen
  • Contributeurs : ~1 000 FCFA / soumission validée
  • Paiements : Flooz & T-Money

Traction

Produit prêt. Preuve terrain à lancer.

  • Produit bout en bout (pas une maquette)
  • Mobile Money intégré — freemium monétisable
  • Aucun MAU / revenu inventé
  • Prochaines preuves : pilotes, 1ers Pro
  • Ambassadeurs & partenariats écoles

Positionnement

Pas un drive WhatsApp.

  • Statu quo : WhatsApp, photocopies, PDF
  • Apps révision génériques — peu locales
  • EZOA-TO : focus Togo + validation humaine
  • Flooz / T-Money · contributeurs · hors ligne
  • Concurrent réel = le chaos informel

Go-to-market

Écoles, élèves, Mobile Money.

  • Pilotes : 3–5 lycées (Lomé / régions)
  • Ambassadeurs élèves & profs récompensés
  • Campagnes WhatsApp / Facebook — examens
  • Licence B2B établissements (forfait annuel)
  • Notifications ciblées par classe
